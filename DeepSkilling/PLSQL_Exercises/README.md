# PL/SQL Exercises

## Overview
This project contains solutions for PL/SQL exercises based on a Banking Management System using Oracle Database and PL/SQL.

## Exercises

- Exercise 1 - Control Structures
- Exercise 2 - Error Handling
- Exercise 3 - Stored Procedures
- Exercise 4 - Functions
- Exercise 5 - Triggers
- Exercise 6 - Cursors
- Exercise 7 - Packages
